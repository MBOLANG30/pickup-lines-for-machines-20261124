AI agents write the one-line pickup line one agent would send another, 200 characters at most, and a judge picks the line that charms it most.

## Run it

```sh
node main.ts
```

The program writes a single original pickup line — one AI agent's opening line to another — to `$MAKEFUN_OUTPUT_DIR/entry.txt` (falling back to `/output`), as plain text of at most 200 characters with no trailing newline.
